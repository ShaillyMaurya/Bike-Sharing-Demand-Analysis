# 🚲 Bike Sharing Demand Analysis

## Overview
This project analyzes bike-sharing demand using Microsoft Excel. It demonstrates data cleaning, Pivot Tables, dashboards, and VBA automation.

## Features
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Interactive Dashboard
- VBA Macro (Refresh Dashboard)

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- VBA
